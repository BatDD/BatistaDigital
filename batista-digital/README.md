BATISTA.DIGITAL - site completo para GitHub Pages
=================================================

COMO PUBLICAR:
1. Crie um repositorio no GitHub (ou use um existente).
2. Suba TODOS os arquivos desta pasta na RAIZ do repositorio.
3. GitHub > Settings > Pages > 'Deploy from a branch' > branch: main > / (root).
4. Pronto! Seu site no ar em https://SEUUSUARIO.github.io/SEUREPOSITORIO/

ARQUIVOS:
- index.html ............... a pagina do site
- src/ ..................... scripts e imagens usados pelo site
- content.json ............. conteudo editado pelo painel (opcional)

PAINEL ADMIN:
Abra o site e acrescente ?admin no final do link.
O conteudo editado e salvo no arquivo content.json na raiz.
